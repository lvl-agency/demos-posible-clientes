# Regla: Demos web para clientes

## Entrada
- El usuario proporcionará un enlace de Linktree o una red social.
- Analiza la información pública accesible del negocio, su nicho,
  servicios, identidad visual y público objetivo.
- Si el enlace no es accesible, no inventes información.
- Si el link es public o no funciona, el agente debera comentarlo y no hacer nada

## Diseño
- Antes de diseñar, abre las demos ya existentes en la raíz y anota paleta, tipografía, layout y componentes de cada una.
- Cada demo debe tener un diseño único, distinto y muy variado respecto de todas las demás. No debe compartir esqueleto visual.
- El sistema visual sale del nicho: una clínica, un spa y una inmobiliaria no pueden verse como la misma plantilla con otros colores.
- Cambia entre demos, de forma visible, la paleta, la familia tipográfica, la composición del inicio, la forma de los bloques y el carácter de los botones.
- Queda prohibido repetir este molde: barra superior sobria, titular en serif, hero en dos columnas y secciones en lista editorial.
- Dentro de un mismo cliente, Basic y Professional sí comparten estilo. Lo que cambia es la amplitud.
- Crea diseños originales, premium y adaptados al nicho.
- No copies el diseño de Linktree ni de las redes sociales.
- Utiliza imágenes de calidad y genera imágenes cuando sea necesario.
- Prioriza una apariencia moderna, profesional y responsive.
- Incluye textos comerciales atractivos y llamadas a la acción.
- No inventes precios, testimonios, certificaciones ni datos reales.
- Usa marcadores claros cuando falte contenido real.

## Versiones

### Basic
- Debe contener exactamente 5 secciones.
- Selecciona las 5 secciones esenciales para el negocio.
- Incluye información principal, servicios y contacto.
- Mantén un diseño profesional, primium, segun nicho, y atractivo.
- Debe de verse igual de bien

### Professional
- Crea un sitio más completo, premium y personalizado.
- Selecciona módulos relevantes según el nicho y sus necesidades.
- Puedes incluir galería, planes, equipo, testimonios, preguntas
  frecuentes, servicios u otros módulos apropiados.
- Evita agregar módulos innecesarios.
- Diferencia claramente esta versión de Basic,
  contenido y amplitud.
- Solo agrega los nombres de los modulos necesario segun la investigacion
- No desarrolles la vista, solo el modulo, si desarrolla el home.
- El estilo se debe mantener

## Selector de versiones
- El selector debe estar dentro de index.html.
- Ubícalo en un header superior, visible y fácil de identificar.
- Utiliza pestañas o tabs para alternar entre Basic y Professional.
- El cambio de versión debe funcionar sin abrir otra URL.
- No muestres precios en el selector ni en el header.
- Ambas versiones deben conservar sus características visuales
  al alternar entre ellas.
- El selector debe funcionar correctamente en móviles y PC.

## Tecnología
- Usa HTML, CSS y JavaScript vanilla.
- No uses React, frameworks, backend ni instalaciones.
- Mantén el código organizado y fácil de modificar.
- No simules funcionalidades reales que no estén implementadas.

## Archivos y carpetas
- Crea una carpeta por cada posible cliente directamente en la raíz.
- Usa un nombre corto, descriptivo y seguro para la carpeta.
- Cada cliente debe tener su propio index.html y carpeta img/.
- Guarda dentro de img/ las imágenes correspondientes al cliente.
- No sobrescribas ni elimines las demos de otros clientes.
- No crees presentacion.html ni documentos de presentación comercial.
- index.html debe contener ambas versiones y el selector superior.

Ejemplo de estructura:

clinica-dental-ejemplo/
  index.html
  img/

inmobiliaria-ejemplo/
  index.html
  img/

## Verificación
- Comprueba que las pestañas alternen correctamente las versiones.
- Verifica que Basic tenga exactamente 5 secciones.
- Comprueba imágenes, enlaces y diseño responsive.
- Confirma que la demo nueva no repite paleta, tipografía ni composición de las demos ya creadas, y que el resultado se reconoce como propio de ese nicho.
- Asegúrate de que cada demo utilice sus propios recursos.
- Informa la carpeta creada y cómo visualizar el resultado.
